# Assignment 4.4 — Metadata & Page Setup

**File name: `index.html`**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>My Portfolio</title>
    <meta name="description" content="My personal portfolio and web development projects.">

    <link rel="icon" href="images/favicon.ico">
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Welcome to My Portfolio</h1>
    <p>This is my personal webpage.</p>
</body>
</html>
```

**Folder structure:**
```text
project/
├── index.html
├── style.css
└── images/
    └── favicon.ico
```

**Submission:** Add a favicon file inside `images`, verify the CSS and image paths, open the page in Chrome, and submit the updated HTML file with a screenshot showing the favicon.
